# わたよし

**社内SE / 一人情シス・アジャイル開発**

> 使い手にシステムを寄せていく持続可能な仕組み作り。

必要なものをつくって、直して、高速PDCAで一人アジャイル開発・運用をしています。<br />
・社内業務の一部を業務アプリに置換（Wordpress使用）▶社内コミュニケーションコスト削減<br />
・音声入力アプリを作成し、電話中の音声をPC上でリアルタイム文字起こし▶タイピング時間の削減<br />
・APIや各種LLM連携をし、メールから各種Saasへ横断連携するツールやプラグインの開発で業務効率化<br />
・GASやPythonからC#・PHPなど、実現したいものを言語にとらわれずに実装・運用しています。<br />
