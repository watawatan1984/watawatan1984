# わたよし

**社内SE / 一人情シス・アジャイル開発**

> 使い手にシステムを寄せていく、持続可能な仕組み作り。

必要なものをつくって、直して、高速PDCAで一人アジャイル開発・運用をしています。

- 社内業務の一部を業務アプリに置換（WordPress）→ コミュニケーションコスト削減
- 音声入力アプリで、電話中の音声をリアルタイム文字起こし → タイピング時間の削減
- API / LLM 連携で、メールから各種 SaaS へ横断連携 → 業務効率化
- GAS・Python から C#・PHP・Ruby まで、言語にとらわれず実装・運用
